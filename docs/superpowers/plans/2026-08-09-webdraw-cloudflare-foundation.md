# Webdraw Cloudflare Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every operational deco dependency with a standard Vite + Cloudflare Worker application using OpenRouter OAuth, D1-backed folders and drawings, and same-origin typed HTTP APIs.

**Architecture:** The React SPA and one Hono Worker deploy together through the official Cloudflare Vite plugin. The Worker owns OAuth, encrypted OpenRouter credentials, opaque sessions, D1 access, and `/api/*`; the browser owns only UI state and calls same-origin JSON endpoints.

**Tech Stack:** React 19, Vite, TypeScript, Hono, Zod, Cloudflare Workers, D1, OpenRouter OAuth PKCE, Vitest, Cloudflare Vitest pool, Testing Library, ESLint, Wrangler.

## Global Constraints

- Use a standard Cloudflare Worker and the official `@cloudflare/vite-plugin`; no deco runtime, CLI, generated types, tools, OAuth, bindings, or deployment commands may remain operational.
- Use `wrangler.jsonc`, compatibility date `2026-08-09`, `nodejs_compat`, generated Worker types, and structured observability.
- Use D1 directly through the `DB` binding and prepared statements.
- Use OpenRouter OAuth PKCE S256 as the sole identity provider for this release.
- Never expose or log the OpenRouter API key; encrypt it with AES-GCM using `AUTH_ENCRYPTION_KEY` from a Worker secret.
- Store only SHA-256 hashes of opaque session tokens; browser cookies are `Secure`, `HttpOnly`, and `SameSite=Lax`.
- Start with an empty database; do not migrate localStorage or DECONFIG content.
- Preserve the user's existing uncommitted URL-loading and Excalidraw initial-data changes when modifying overlapping frontend files.
- Use test-driven development for behavioral code and make one focused commit per task.
